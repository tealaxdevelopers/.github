# Tealax — GitHub organization files

This repository contains Tealax's organization profile and reusable community-health files. The organization profile is rendered from `profile/README.md` when this repository is public and named `.github`.

## Organization profile languages

- `profile/README.md` — default profile shown on GitHub (English)
- `profile/README_en.md` — English version
- `profile/README_tr.md` — Turkish version

The default profile links to both language variants.

## Included community files

- `CONTRIBUTING.md` — contribution and source-provenance expectations
- `SECURITY.md` — responsible vulnerability reporting guidance
- `CODE_OF_CONDUCT.md` — community expectations
- `ISSUE_TEMPLATE/` — bug report, feature request, and issue configuration
- `PULL_REQUEST_TEMPLATE.md` — pull request checklist

## Before publishing

1. Confirm all linked projects are appropriate to feature publicly.
2. Check licensing and provenance per repository; these community files do not license code in other repositories.
3. Keep private repository names, secrets, personal data, API keys, and internal URLs out of the profile.
4. Ensure security-sensitive or archived source material is described accurately and not presented as original or safe without verification.
